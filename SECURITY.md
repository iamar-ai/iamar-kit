# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately with GitHub's
private vulnerability reporting: open the **Security** tab of this repository and choose
**Report a vulnerability**.

Include what you found, the steps to reproduce it, and the commit or release you tested.
We will confirm receipt and keep you informed while we work on a fix.

## Scope

In scope: the scripts, tools and tests in this repository, and the catalogue data they read.

Out of scope: the iamar browser and hub, which are run separately. Report problems with those
through the same private channel and say which service they affect.

## Secrets

Never put keys, tokens, `.env` files or service-account files in an issue, a pull request or a
commit. If you find one in this repository, report it privately as above.
