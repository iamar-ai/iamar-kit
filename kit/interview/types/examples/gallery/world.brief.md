# Design brief: gallery example

A bright hall showing twelve of my watercolour paintings along one loop.

- Track B (worlds/glass_hall/style.json), type gallery, visitors: public, up to 15 at once.
- Budgets (low tier): 120000 triangles, texture size 1024, texture bytes 100663296, download 90 MB.
- Defaults I chose, please review: G1, G2.
- Features: ui_plaques, script_tour.
- Checkpoints: greybox, scale check, paint.
